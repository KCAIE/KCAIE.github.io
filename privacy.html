Privacy policy

Last updated 12 November 2026

Who uses this app

The Odd Fathoms Google app is a private tool used only by the owner of the Odd Fathoms channel to automate posting the channel's own videos. It is not offered to the public.

What Google data it uses

  • YouTube: to upload videos to the owner's own channel and set their details, such as title, description and privacy.
  • Google Drive: to save finished video files in the owner's Drive.
  • Google Sheets: to read and update the owner's own list of video topics.

What it does not do

It does not collect data about viewers or anyone else, does not sell or share any data, and does not use Google data for advertising. Data is only used to carry out the uploads described above.

Storage and removal

Files stay in the owner's own Google account. Access can be removed at any time from the Google Account permissions page.

Google API Services

Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Contact

Questions can be raised on the site's GitHub page.
